### 如何寻找高质量的依赖包

在满足硬性指标(如满足 python最低版本与开源协议)后，若仍有多个包能完成相同的功能，则可以参考以下指标:

- 周下载量: 热门与否, 一般与github星标数成正比
- github 上次提交时间/星标数/PR占fork比值/issues的开启百分比: 更新频率与质量
- 依赖的上游包数量与质量: 综合影响打包的安全与质量

### 个人经验
不包含任何AI的工具基座:harness

#### AI控制浏览器

[playwright]: 自动化测试、爬虫、自动点击或交互。支持获取网络请求等F12开发者工具里的数据辅助调试。

[playwright-cli]: 对shell友好，成功率较高。snapshot功能会将 包含各种可交互元素的无障碍访问树转为markdown给AI，但由于大部分网页不注重aria-*属性，且snapshot不包含css样式，首次构建选择器正确率偏低。

[playwright-mcp]: 渐进式披露，但成功率比cli似乎更低。在尝试调用 unsafe_eval 与 evalutate 时总会有一个失败。尚不清楚原因

[browser-use]: 基于playwright。

[browser-harness]: 基于 chrome-cdp，能访问浏览器更底层的数据，但一般用不到。

[crawl4ai]: 纯AI控制，人类无法介入辅助操作浏览器。但是提取的markdown比playwright的snapshot更干净一些。

#### AI编写文档

[ppt-master] 生成可编辑ppt的最佳解决方案，通过中间件svg的过渡，将markdown转为真正可编辑的pptx。

#### 科学计算&AI深度学习

[cv2]

[numpy] 基于C语言编写的，利用CPU SIMP告诉处理科学数据(矩阵)

[pytorch] 专为深度学习，提供常见算子。

[gradio](../gradio) 专为AI快速搭建单页网页入口，因为官方支持40多种常见组件(音/图/聊/视频/图表/3D)而无需js/css专业知识，
支持暴露Rustful API(与其他语言对接请求响应)、聊天机器人、基于hugging face服务器内网穿透的在线分析。若要深度定制，则不建议用本库。

#### 后端

[fastapi] 快速搭建Restful API服务

[pydantic] 数据验证模型

[aiohttp] 类似 requests urllib3 的异步框架，可用作客户端

#### 测试

[pytest]

[playwright] 有 ts/python 版本。

#### CLI

[argparse] python官方的shell命令解析

[argcomplete] shell动态补全

#### shell

[pexpect] 热门的 shell 交互工具

[aexpect] 对windows支持更好，但没有 pexpect 热门。

#### 配置

[pyyaml]

[toml] python官方
